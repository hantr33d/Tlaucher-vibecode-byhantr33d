CLIENTMOD (Forge 1.16.5) + ЛАУНЧЕР С КНОПКОЙ PLAY

ШАГ 1. Один раз поставь Forge 1.16.5 через TLauncher
  - Открой TLauncher, выбери версию "1.16.5" с галочкой Forge, нажми "Установить и играть".
  - Дождись главного меню Minecraft и закрой игру.
  (Это скачает Minecraft и все библиотеки. Наш лаунчер сам Minecraft не скачивает.)

ШАГ 2. Собери мод и лаунчер на GitHub (бесплатно, ничего ставить не надо)
  1. Зайди на github.com, зарегистрируйся, создай новый репозиторий.
  2. Загрузи туда ВСЁ содержимое этой папки (Add file -> Upload files),
     вместе со скрытой папкой .github (лучше с компьютера).
  3. Вкладка Actions -> build -> Run workflow. Подожди 5-8 минут.
  4. Открой готовый запуск, внизу в Artifacts скачай "ClientMod-Package" и распакуй.
     Внутри два файла: ClientLauncher.exe и clientmod-1.0.jar.

ШАГ 3. Играй
  - Положи оба файла в ОДНУ папку (например Рабочий стол\ClientMod).
  - Запусти ClientLauncher.exe (Windows может показать предупреждение
    "неизвестный издатель": Подробнее -> Выполнить в любом случае).
  - Впиши ник, выбери RAM (4 ГБ), нажми PLAY. Откроется Minecraft с модом.
  - Нужна Java 8. Лаунчер ищет её сам (из папки TLauncher). Если не нашёл - кнопка Browse.

УПРАВЛЕНИЕ В ИГРЕ
  Правый Shift   меню мода (вкладки HUD / Combat / Movement / Visuals / Player / Misc / Settings)
  C (держать)    Zoom
  Settings -> Open HUD Editor: перетаскивай элементы HUD мышкой
  .bind Fly G    повесить модуль на клавишу   (.bind Fly none  - убрать)
  .friend add ник / .enemy add ник / .friend list
  .sky ff00aa   .particles 33f0ff   .fog 88ccff     любой цвет в hex
  .autobuy item алмаз   .autobuy price 5000   (AutoBuy на аукционе/магазине)
  .save          сохранить (и так сохраняется само)

ВАЖНО
  Мод тестировался только на бумаге: если GitHub-сборка упадёт, скопируй текст ошибки из Actions и отправь.
  Использовать на своём сервере или с согласия друга: на публичных серверах античит банит.
